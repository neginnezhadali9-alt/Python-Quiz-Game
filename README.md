# Python Quiz Game 

A simple interactive quiz game built with Python. The program asks me multiple-choice questions, checks the user's answers, and calculates the final score.

## Features

1. Displays 5 multiple-choice questions.
2. Shows four options for each question.
3. check whether the answers are correct or incorrect.
4. Calculates the final score.
5. Displays the final percentage.
6. shows feedback based on the final result.

## Technologies Used

- Python 3

## Python Concepts Used

- Lists
- Nested lists
- While loops
- Conditional statements (if, else, elif)
- User input (input())
- Indexing
- Variables

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run following command : python game.py

This project was created as a Python practice project to improve my programming skills and understand how lists and loops can be used to built interactive programs.
